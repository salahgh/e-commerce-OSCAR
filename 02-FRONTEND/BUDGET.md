## 12. ROI & Justification

### Pourquoi ce budget?

1. **Équipe optimisée**:
   - Développeurs Next.js junior/mid-level avec encadrement technique
   - Focus sur la qualité avec un coût maîtrisé

2. **Technologies modernes**:
   - Next.js 14 avec App Router et TypeScript
   - Tailwind CSS pour un design moderne
   - Apollo Client pour GraphQL
   - PWA pour expérience mobile optimale
   - Support multilingue avec RTL

3. **Budget optimisé**:
   - Taux horaire junior/mid-level: 185 DZD/heure
   - Outils gratuits: VS Code, GitHub, Vercel, Figma free
   - Infrastructure économique: Vercel gratuit, Cloudflare gratuit
   - Focus sur l'essentiel sans over-engineering

4. **Qualité assurée**:
   - Tests rigoureux
   - Performance optimale (Lighthouse > 90)
   - SEO optimisé avec Next.js
   - Documentation complète
   - Support initial inclus

## 13. Conditions & Hypothèses

### Inclus dans le budget:
- Développement selon spécifications
- Tests (unitaires, intégration, E2E)
- Documentation (Storybook, technique)
- Optimisation performance & SEO
- Support multilingue (AR, FR, EN)
- Support 2 semaines post-livraison

### Non inclus:
- Design UI/UX (sauf option 2)
- Contenu (photos, descriptions produits)
- Infrastructure production
- Maintenance au-delà de 2 semaines
- Évolutions fonctionnelles post-livraison
- Formation utilisateurs finaux

### Hypothèses critiques:
1. **API backend disponible** selon planning (ou mocks fournis)
2. **Designs finalisés** avant semaine 2 (si client fournit)
3. **Contenu fourni** par le client en temps voulu
4. **Validation client** sous 2-3 jours ouvrables
5. **Scope stable** (pas de changements majeurs)
